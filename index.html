Breadth First Search

BFS mencari jalur secara melebar dari titik awal. Algoritma ini memeriksa node terdekat lebih dulu, lalu lanjut ke level berikutnya. Pada grid tanpa bobot, BFS cocok untuk mencari jalur terpendek.

Depth First Search

DFS mencari jalur dengan masuk sedalam mungkin ke satu arah. Jika menemukan jalan buntu, algoritma akan mundur dan mencoba jalur lain. DFS bagus untuk eksplorasi, tetapi belum tentu menghasilkan jalur terpendek.
