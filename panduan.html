DFS & BFS Pathfinding Visualizer

Panduan Singkat Penggunaan Website

Website ini digunakan untuk menampilkan proses pencarian jalur dari titik awal menuju titik tujuan menggunakan algoritma Breadth First Search dan Depth First Search.

Cara Menjalankan Visualisasi

  1. 1. Buka halaman utama website.
  2. 2. Pilih algoritma yang ingin digunakan, yaitu BFS atau DFS.
  3. 3. Pilih kecepatan animasi melalui menu Speed.
  4. 4. Buat rintangan pada grid menggunakan mode Wall.
  5. 5. Klik tombol Start untuk menjalankan visualisasi.
  6. 6. Amati visited node dan path akhir yang terbentuk.

Mode Interaksi Grid

Wall: digunakan untuk membuat atau menghapus tembok pada grid. Klik atau drag kotak untuk membuat banyak rintangan.

Start: digunakan untuk memindahkan titik awal pencarian. Pilih mode Start, lalu klik kotak tujuan.

End: digunakan untuk memindahkan titik akhir pencarian. Pilih mode End, lalu klik kotak tujuan.

Fungsi Tombol pada Website

Start

Menjalankan algoritma yang dipilih untuk mencari jalur.

Algorithm

Memilih algoritma BFS atau DFS.

Speed

Mengatur kecepatan animasi visualisasi.

Generate Maze

Membuat maze atau rintangan otomatis.

Clear Path

Menghapus hasil pencarian tanpa menghapus wall.

Clear Board

Menghapus seluruh wall dan mengembalikan board seperti awal.

Breadth First Search

BFS mencari jalur dengan cara melebar dari titik awal. Algoritma ini memeriksa node yang paling dekat terlebih dahulu, kemudian lanjut ke node berikutnya. BFS cocok digunakan untuk mencari jalur terpendek pada grid tanpa bobot.

Depth First Search

DFS mencari jalur dengan cara masuk sedalam mungkin pada satu arah. Jika menemukan jalan buntu, algoritma akan kembali dan mencoba jalur lain. DFS dapat menemukan jalur, tetapi belum tentu menghasilkan jalur terpendek.
